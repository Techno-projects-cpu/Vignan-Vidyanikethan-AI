    OFFLINE AI

    Real local model

    Open-weight Meta / SmolLM2 / Qwen models run in this browser with Vignan's own textbook rules.

    Checking device…
    No key · no training. WebLLM downloads one model the first time, then caches it on this device. Questions, answers, quizzes, flashcards and grading can run locally. The deterministic cited-excerpt engine remains the final fallback.
    Checking browser cache…

    WebGPU is required for the in-browser model. On laptops without it, run ollama pull llama3.2:1b and choose Ollama below; on phones, the cited-excerpt engine still works offline.

    FREE KEYS

    Official free-tier API keys

    Generate your own keys. Put them in Render → Environment, never in Git. You can paste several keys into one variable.

    $0 budget
    STUDENT KEYS

    Your own API keys

    Optional bring-your-own-key fallback. Used only after the school's Render keys are exhausted.

    Local only
    Private by default. Your keys stay in this browser. They are sent to this site's /api/ai only for the current request, never saved to your account, leaderboard or data exports. Do not add keys on a shared computer unless you clear them afterwards.

    MODEL ROUTER

    AI engine

    Offline is the default. A connected model is optional.

    Checking server…
    No model training · $0 budget. Vignan Vidyanikethan AI orchestrates existing AIs. Choose the local WebLLM model, the server's free router (Gemini, Groq, Cloudflare, OpenRouter, Mistral, Cohere, Arena), Ollama, or any OpenAI-compatible endpoint. Textbook passages stay the source of truth.

    How this works

    Your books are split into page-preserving passages. A local hybrid search finds evidence; the offline engine quotes it with citations. If you connect a model, only those short passages are sent. Web results are labelled as outside your textbooks.

    1. Upload PDFs or paste notes in Library.
    2. Ask a question; Vignan Vidyanikethan AI retrieves the best passages with page numbers.
    3. A local open model, the free router, or the offline excerpt engine writes the answer from those passages.
    4. Generate a quiz, get instant feedback, and share a funky edit video.
