01 / What it is — and what it is not

Every school AI project this year will be "an AI that answers questions". The interesting question is why anyone should believe the answer. This project's answer is a constraint: the AI may only answer from pages the student actually has, and every sentence it claims to be sourced must carry a book, chapter and page. When the saved pages cannot support a question, the app says so and offers a different route rather than inventing one.

Built on free tiers only: Render for hosting, GitHub for the code, Supabase for accounts, and the student's own free AI keys. No paid dependency, no shared key, no advertising, no analytics.

02 / Test one: the citation

This is the claim that matters most, so test it first, in about twenty seconds.

  1. Add a page you can open by handUse Add book with a PDF, a photo of a page, or a few paragraphs of text. Any page works — even one you typed yourself for this test.
  2. Ask something that is only in that pagePick a sentence with a number, a date or a term in it, and ask about that.
  3. Read the citation under the answerIt names the file and the page number, and quotes the sentence it used.
  4. Open the page and check itThe quoted sentence should be there, on that page. If it is not, that is a bug and we want to hear about it.

"It won't answer from nothing. If the book doesn't cover it, it says so — and only then does it offer a labelled web search instead."

04 / Updates ask first

A new version never replaces itself mid-lesson. It installs, then waits. A banner offers Update now or Later, and nothing is uploaded either way — books, decks and chats stay in the browser.

"You can see the banner, the release number and the offline readiness in Settings. The student stays in control of the tool."

05 / Questions a judge usually asks

Isn't this just a wrapper around ChatGPT?
Wrapper is fair, if it stops there. The work is the constraint layer: a page-level retrieval index that runs in the browser, an answer path that is refused when evidence is thin, a citation that has to name a page, an offline fallback that degrades in a defined order, and a local model option so it can run with no cloud at all. Plenty of wrappers answer anything; this one declines when it cannot show its working.
Why not train your own model?
Because a school project cannot train a model that beats the ones already available, and pretending otherwise would waste the effort. The scarce thing here is not another model — it is a trustworthy study loop around the models that exist.
What if the provider is down or the key runs out?
Keys rotate automatically, a rate-limited key is retired for a minute, and the app falls back through several providers. If every key fails, the answer comes from the student's own pages instead of failing outright.
Is student data being sold or trained on?
There is no analytics, no advertising identifier and no data broker. Books, chats and results stay in the browser; only the text needed for one answer is sent to the provider that writes it. The details are in the privacy policy, written in plain language.
What stops it from making up a page number?
Two things: the answer refuses the built-in fallback when retrieval found evidence, and the citation shown is assembled from the retrieved chunk itself, not from the model's sentence. That is also why we ask you to open the page and check.

06 / Honest limitations

  • No textbook is bundledThe publisher's permission has not been granted, so the app ships empty and the student adds their own pages. That is a copyright decision, not a technical gap.
  • Free hosting sleepsAfter a quiet period the Render service takes about half a minute to wake. During the demo, load the page once before you start.
  • The local model is optional and heavyRunning a model in the browser needs a capable device and a large one-time download. It exists so the app can work with no cloud, not as the default.
  • Offline means your own pagesWith the network off, answers come from saved material. It is a study fallback, not a search engine in your pocket.
  • One student, no auditThere has been no professional security audit. The protections in place, and what is deliberately not collected, are listed on the security page.
