# The documentation

Everything in this folder is documentation. Nothing here is served, cached or
downloaded by the app: the offline cache lists pages, scripts, stylesheets,
fonts and icons, and skips Markdown on purpose. Opening a `.md` file on a phone
with the Wi-Fi off is not a promise the project makes, and it does not need to.

| File | What it is for |
| --- | --- |
| [STRUCTURE.md](./STRUCTURE.md) | The map: what lives where, and why the root is shaped the way it is |
| [DESIGN.md](./DESIGN.md) | The visual law, the deliberate breaks from generic advice, and how the design was audited |
| [SKILLS.md](./SKILLS.md) | The external design skills this project has read, what was taken from each, and what was deliberately not run |
| [CHECKLIST.md](./CHECKLIST.md) | The printable pass/fail sheet for a demo that still needs a human and a phone |
| [DEPLOY.md](./DEPLOY.md) | Exact Render and Supabase steps, with rotation and verification |
| [LOCAL_AI.md](./LOCAL_AI.md) | The bundled on-device model: which one, how big, and what it may answer |
| [PACKAGING.md](./PACKAGING.md) | The honest answer to "can I install this as an app" |
| [OPEN_SOURCE_CREDITS.md](./OPEN_SOURCE_CREDITS.md) | What was read, what was borrowed (nothing in code), and what was not |

The three files that stay in the repository root are the ones the world reads
before it reads anything else: `README.md` (what this is), `LICENSE` (what you
may do with it) and `SECURITY.md` (how to report a problem privately).
